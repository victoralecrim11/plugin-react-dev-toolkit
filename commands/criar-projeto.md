# /criar-projeto

Identifique plataforma, nível, objetivo e escopo. Gere um MVP funcional com TypeScript estrito, sem classes e sem dependências legadas. Use `react-core` e a extensão correta; em seguida registre o projeto no dashboard.

Entregue: estrutura de pastas, arquivos iniciais, comandos de execução, justificativas curtas e próximos passos. Prefira Context/Hooks; use Zustand somente para estado global compartilhado. Use TanStack Query para estado remoto.
