MANUAL INTERATIVO

React Dev Hub

Uma base prática para construir, evoluir e acompanhar projetos React.

1. Configure

/setup registra seu nível e a pasta-base, sobe o Project Hub e entrega este manual. É por máquina, não por projeto — e pode rodar de novo quando quiser trocar o perfil.

2. Construa — por projeto

/criar-projeto lê o perfil salvo e pergunta só o que é do projeto. Depois, /criar-componente. Todo código é TypeScript e explica as decisões.

3. Revise

/review verifica qualidade, acessibilidade, erros, performance e dívida técnica sem mudar comportamento sem motivo.

4. Acompanhe

/dashboard reabre o Project Hub local em 127.0.0.1:8766. Os dados ficam em JSON no seu computador.

Seu perfil fica salvo

O nível de calibração é informado no /setup e persiste em dashboard-config.json. Todos os comandos leem esse valor para ajustar a profundidade das explicações e o teto de complexidade arquitetural — nenhum deles repergunta. Para trocar de nível, rode /setup outra vez: ele mostra o que está salvo e altera só o que você pedir.

Decisões padrão

  • React: TypeScript, Hooks, Context/Zustand e TanStack Query.
  • Next.js: App Router, Server Components e Server Actions quando adequados.
  • Mobile: Expo, Expo Router, Hermes e Reanimated.
