MANUAL INTERATIVO

React Dev Hub

Uma base prática para construir, evoluir e acompanhar projetos React.

1. Configure

Use /setup para informar plataforma, nível e objetivo. O plugin sugere a arquitetura mais simples que atende ao MVP.

2. Construa

Use /criar-projeto e /criar-componente. Todo código é TypeScript e explica as decisões.

3. Revise

/review verifica qualidade, acessibilidade, erros, performance e dívida técnica sem mudar comportamento sem motivo.

4. Acompanhe

Use /dashboard e abra o Project Hub local em 127.0.0.1:8766. Os dados ficam em JSON no seu computador.

Decisões padrão

  • React: TypeScript, Hooks, Context/Zustand e TanStack Query.
  • Next.js: App Router, Server Components e Server Actions quando adequados.
  • Mobile: Expo, Expo Router, Hermes e Reanimated.
